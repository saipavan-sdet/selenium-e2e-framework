# Selenium E2E Automation Framework

## Overview
End-to-end Selenium automation framework built using Java, TestNG, and Maven following Page Object Model (POM).

## Tech Stack
- Java
- Selenium WebDriver
- TestNG
- Maven
- Git / GitHub

## Features
- Page Object Model design
- Reusable base test setup
- Cross-browser ready
- TestNG HTML reports

## How to Execute
```bash
mvn clean test
